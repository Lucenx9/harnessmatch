# Homepage override

The homepage is a working analysis surface. It should feel closer to a compact research console than a marketing landing page.

## Page job

- Let a user select a concrete coding workflow and compare harness fit immediately
- Keep scenario assumptions, scoring weights, required gaps, source dates, and methodology within one interaction path
- Route users to evidence profiles without inserting promotional sections between the chart and catalog

## Layout

- Compact two-column intro: purpose on the left, dataset status on the right
- Full-width workflow-fit explorer immediately below the intro
- Horizontal bars for seven active harnesses, sorted by the deterministic fit score
- Capability-filtered catalog after the chart
- No testimonial, social proof, generic benefit, or conversion CTA sections

## Chart rules

- One muted violet series with direct numeric labels
- No background progress tracks; quiet vertical gridlines provide the scale
- Pattern plus text identifies missing required capabilities
- Scenario controls remain keyboard-operable and horizontally scroll only within their own control row on small screens
- Provide an accessible table and CSV download for every scenario
- State explicitly that fit points are not benchmark performance

## Responsive behavior

- At 1040px the intro stacks and scenario metadata moves from six to three columns
- Below 720px metadata uses two columns, chart labels contract, and only 0, 50, and 100 scale labels remain
- The page itself never scrolls horizontally
